# Manav & Aarohi | Wedding Invitation

Interactive digital wedding invitation website.

## Features
- Interactive hero section with couple details
- Moments photo gallery with smooth scroll reveal
- Wedding celebration schedule
- Venue details with Google Maps direction link and QR code
- Live countdown timer
- Falling petals particle animation

## Getting Started
Open `index.html` in your web browser or serve locally:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
